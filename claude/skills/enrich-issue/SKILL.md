---
name: enrich-issue
description: Use this skill whenever you're asked to optimize/enrich the description of a GitHub issue.
---

Read the provided GitHub issue, try to understand the intent, analyze the codebase for relevant code and enrich the issue description with (technical) information.

Make sure you never drop any information on the issue, when editing it. Only rewrite or add information while keeping the original intent intact.

When referencing code in the issue description, use GitHub permalinks with the current commit hash instead of just plain line numbers.

Before editing the issue description, ask for confirmation on the planned description text.
